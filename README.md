## Project Overview

This project uses supervised machine learning regression algorithms to predict house prices from housing data. It covers data exploration, preprocessing, model training, performance evaluation, and visualization.

**Objective:** Compare multiple regression models and identify the leading candidate based on test-set performance.

##  Project Objectives

* Explore and prepare the housing dataset.
* Handle categorical features and prepare model inputs.
* Train and compare four regression algorithms.
* Evaluate predictions using standard regression metrics.
* Visualize results and assess model performance.

## Tools & Technologies

* **Language:** Python
* **Environment:** Jupyter Notebook
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Machine Learning:** Scikit-learn

##  Machine Learning Models

| Algorithm               | Type                     |
| ----------------------- | ------------------------ |
| Linear Regression       | Linear Model             |
| Ridge Regression        | Regularized Linear Model |
| Decision Tree Regressor | Tree-Based Model         |
| Random Forest Regressor | Ensemble Model           |

## Model Evaluation

The models are evaluated using the following metrics:

* **MAE:** Mean Absolute Error
* **MSE:** Mean Squared Error
* **RMSE:** Root Mean Squared Error
* **R² Score:** Explained variance in the target variable

### Best Performing Model

Based on the test-set results, **Linear Regression** emerged as the leading candidate.

| Metric   |    Result |
| -------- | --------: |
| RMSE     | 49,455.08 |
| MAE      | 39,517.15 |
| R² Score |    0.5792 |

*Note: These results depend on the dataset, preprocessing, and train-test split.*
